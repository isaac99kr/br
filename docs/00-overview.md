# 00. 제품 개요

## 한 줄 정의

**246일 성경 읽기 일정**을 따라가며, 진행 상황을 확인하고 **이전에 읽던 곳부터 이어서** 읽을 수 있는 웹사이트입니다.

단순한 일정표가 아니라, 읽기 상태(안읽음 / 읽기 시작 / 완료)와 이어 읽기를 중심으로 합니다.

## 핵심 원칙

1. **일정 원천은 CSV만** — [`asset/schedule/bible_reading_schedule.csv`](../asset/schedule/bible_reading_schedule.csv) 기준. 임의로 일정을 만들거나 바꾸지 않습니다.
2. **365일 일정은 사용하지 않습니다.** 실제 일정은 **1일차 ~ 246일차**입니다.
3. **구약 31주차 / 신약 11주차**로 날짜 찾기 화면을 구성합니다.
4. **서버·DB·로그인 없음** — 정적 사이트 + 브라우저 `localStorage`로 진행 기록만 저장합니다.
5. **후속 기술 스택:** React SPA, GitHub Pages 배포 (`/br/` 경로 고려).
6. 구현 전에 저장소·데이터·디자인을 조사하고, **단계별로 검증**합니다. (이번 단계는 기획·자료 정리까지)

## 사용자 가치

| 니즈 | 대응 |
|---|---|
| 지금 얼마나 읽었는지 알고 싶다 | 홈 진행률·완료 일수 |
| 이어서 읽고 싶다 | 이어 읽기 → 마지막 읽기 날짜 |
| 특정 날짜를 찾고 싶다 | 구약/신약 → 주차 → 날짜 카드 |
| 본문을 읽고 싶다 | 날짜별 읽기 화면 (개역개정 / 표준새번역 선택) |

## 화면 구성 (요약)

1. **홈 / 진행 상황** — 진행률, 이어 읽기
2. **날짜 찾기** — 권역·주차별 일정 탐색
3. **성경 읽기** — 선택한 날짜의 범위·본문·상태 변경

상세는 [02-information-architecture.md](02-information-architecture.md), [04-ui-screens.md](04-ui-screens.md)를 참고하세요.
