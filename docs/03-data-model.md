# 03. 데이터 모델

## 1. 읽기 일정 CSV

경로: [`asset/schedule/bible_reading_schedule.csv`](../asset/schedule/bible_reading_schedule.csv)

### 컬럼

| 컬럼 | 의미 | 예시 |
|---|---|---|
| `reading_day` | 일정 번호 (1~246) | `1` |
| `weekday` | 요일 약어 | `월` |
| `testament` | 권역 | `구약` / `신약` |
| `week_no` | 권역 내 주차 | `1` |
| `reading_range` | 그날 읽을 범위 표시 문자열 | `창1-3장` |

- 구분자: **세미콜론 (`;`)**
- 인코딩: UTF-8

### 검증 결과 (원본 기준)

| 항목 | 결과 |
|---|---|
| 데이터 행 수 | 246 |
| `reading_day` 범위 | 1 ~ 246 |
| 누락·중복 | 없음 |
| 구약 | 183일, 주차 1~31 |
| 신약 | 63일, 주차 1~11 |

구현 시에도 CSV를 파싱한 뒤 동일 검증을 수행합니다. 검증 실패 시 임의 일정을 만들지 말고 오류를 표시합니다.

### 일정 레코드 (정규화 후 권장 형태)

```json
{
  "day": 1,
  "weekday": "월",
  "testament": "구약",
  "week": 1,
  "range": "창1-3장"
}
```

CSV 원본은 수정하지 않습니다. 앱에서는 정적 JSON/모듈로 변환해 쓸 수 있으나 내용은 동일해야 합니다.

### `reading_range` 복잡 패턴 예시

본문 연결 시 파서가 대비해야 할 패턴입니다.

| day | reading_range | 특징 |
|---|---|---|
| 1 | `창1-3장` | 단일 권, 장 구간 |
| 20 | `민9:1-14, 민1-3장` | 절 구간 + 장 구간, 쉼표 연결 |
| 22 | `민7-8장, 민9:15-23, 민10장` | 혼합 |
| 56 | `삼상18-20장, 시59편` | 다권, 시편은 `편` |
| 57 | `시1-2편, 시4-6편, 시8-17편, 삼상21장, 시34·56편` | `·` 로 비연속 편 |
| 184 | `눅1:1-38, 마1:18-25, …` | 신약 병행 본문 다수 |
| 243 | `요일1-5장, 요이1장, 요삼1장` | 짧은 서신 |

표시용 문자열은 CSV를 그대로 쓰고, 본문 추출은 후속 단계에서 파서로 처리합니다.

### 본문 연결 정책 (후속)

1. 일정에는 범위 문자열만 있고 본문 본문은 없음.
2. 본문 파서가 준비되기 전에는 읽기 화면에 **범위 + 「본문 미연결」안내**만 표시.
3. 본문이 실제로 렌더링될 때만 스크롤 자동 완료를 켭니다.
4. 원본 CP949 파일은 보존하고, 앱용으로는 UTF-8 JSON 등으로 변환할 수 있습니다.
