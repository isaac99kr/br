# 01. 제품 요구사항

## 목표

사용자가 제공된 **246일 읽기 일정**을 따라 성경을 읽고, 진행 상황을 저장·이어서 읽을 수 있게 합니다.

## 포함 범위 (In Scope)

### 화면 A — 홈 / 진행 상황

- 서비스 제목(브랜드): Bible Reading Journey / 성경 읽기
- 전체 일정 수 (CSV 기준, 246)
- 완료한 날짜 수
- 진행률 = `완료 수 ÷ 전체 일정 수` (퍼센트 + 막대)
- **이어 읽기** 버튼
- 날짜 찾기 진입
- 마지막(또는 다음) 읽기 날짜와 성경 범위
- 읽기 기록이 없을 때의 빈 상태 안내

동작:

- 이어 읽기 → `lastReadDay`가 있으면 그 날짜의 읽기 화면, 없으면 **1일차**
- 마지막 읽던 날짜가 `완료`여도 **임의로 다음 날로 건너뛰지 않음** (lastReadDay 유지)
- 진행률에는 **`완료`만** 포함 (`읽기 시작`은 미포함)
- 새로고침 후에도 진행률·마지막 읽기 정보 유지

### 화면 B — 날짜 찾기

- **구약 / 신약** 분리
- 권역 안 **주차별** 날짜 카드 (구약 31주, 신약 11주)
- 각 카드: 날짜 번호, 읽기 범위, 상태 텍스트
- 필터: **전체 / 구약 / 신약 / 미완료만**
- 날짜 클릭 → 해당 읽기 화면
- CSV에 없는 가짜 날짜를 만들지 않음
- 모바일에서 주·날짜 목록이 자연스럽게 재배치

상태 시각 구분 (색상만으로 구분 금지 — 텍스트/아이콘 병행):

| 코드 | 화면 표기 |
|---|---|
| `unread` | 안읽음 |
| `in_progress` | 읽기 시작 |
| `completed` | 완료 |

> HTML 프로토타입의 **「읽는 중」**은 기획상 **`읽기 시작`**으로 통일합니다.

### 화면 C — 성경 읽기

표시:

- 날짜 번호 (DAY n)
- 구약/신약 · 주차 · 요일
- 읽을 성경 범위 (`reading_range`)
- 성경 본문 영역
- 이전 날짜 / 다음 날짜
- 읽기 상태 조작
- 닫기(홈 또는 이전 화면으로)

동작:

1. `안읽음` 날짜를 열면 → `읽기 시작`으로 변경
2. 이미 `읽기 시작` / `완료`이면 열기만으로 상태를 낮추지 않음
3. 이전/다음이 1~246 범위를 벗어나면 비활성화
4. 열 때마다 `lastReadDay` 갱신
5. **실제 본문이 렌더링된 경우만** 본문 영역 끝 스크롤 시 `완료` 자동 처리
6. 본문이 없으면 자동 완료하지 않음 (범위 + 개발용 안내만 표시)
7. 사용자가 완료를 해제하면 → **`안읽음`** (읽기 시작으로 남기지 않음)
8. `안읽음`으로 되돌린 뒤 다시 열면 정상적으로 `읽기 시작`으로 변경 가능

## 읽기 상태 규칙 (요약)

| # | 규칙 |
|---|---|
| 1 | 최초 = `안읽음` |
| 2 | 안읽음 날짜 오픈 → `읽기 시작` |
| 3 | 본문 끝 도달 → `완료` (본문 연결 시에만) |
| 4 | 완료 수동 해제 → `안읽음` |
| 5 | 완료 날짜를 다시 열어도 자동으로 `읽기 시작`으로 되돌리지 않음 |
| 6 | 날짜 찾기에서 상태 확인 가능 |
| 7 | 홈 진행률 = 완료만 집계 |

상세 저장 스키마는 [05-progress-storage.md](05-progress-storage.md)를 참고하세요.

## 비범위 (Out of Scope)

- 계정 / 로그인 / 회원가입
- 서버 API · 데이터베이스
- 기기·브라우저 간 진행 동기화
- **365일** 또는 CSV에 없는 임의 일정 생성
- 성경 본문 전체 임의 생성·가짜 본문
- 과도한 애니메이션·불필요한 UI 프레임워크

## 비기능 요구

- 모바일 우선 반응형, 데스크톱에서도 가독성 유지
- 키보드 포커스·기본 접근성
- 로딩 / 데이터 없음 / 오류 시 흰 화면으로 멈추지 않음
- GitHub Pages (`…/br/`) 경로에서 정적 자산이 깨지지 않도록 (후속 구현)

## 수용 기준 (기획 수준)

- CSV 246일·구약/신약·주차가 화면에 그대로 반영된다.
- 이어 읽기가 마지막 읽기 위치(또는 1일차)로 이동한다.
- 상태 전이·진행률·localStorage 유지가 위 규칙을 따른다.
- 본문 미연결 시 자동 완료가 발생하지 않는다.
